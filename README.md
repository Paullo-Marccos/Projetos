# 🗃️ Paullo-Marccos // Registros de Projetos

> Documentação detalhada do desenvolvimento, motivação e estrutura por trás dos projetos criados.

Este repositório serve como um portal centralizado para catalogar, apresentar e documentar as produções web e os projetos de ARG / enigmas desenvolvidos por **Paullo-Marccos**.

---

**## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estrutura semântica e acessível.
* **CSS3**: Estilização baseada em variáveis de cor (`:root`) e tipografia imersiva (*IBM Plex Mono* e *Fraunces*).
* **JavaScript**: Manipulação de registos, áudio e efeitos visuais em tempo real.
